Safety and technical limits

This project collects only publicly displayed business information and intentionally avoids access-control bypasses.

✓

Designed to do

  • Collect visible Google Business fields
  • Respect website robots.txt rules
  • Scan public company/contact pages
  • Checkpoint results after each listing
  • Keep job history on persistent storage
!

Will not do

  • Bypass CAPTCHA, login or rate limits
  • Scrape private personal profiles
  • Guarantee unpublished email or phone data
  • Use hidden API keys or paid providers
  • Run several browser jobs at the same time
◎

Recommended workflow

Start with 5 results in Google-only mode. When that succeeds, test Website mode. Use Full mode only for smaller batches because public social pages are slower and may require login.

1Google test→2Website enrich→3Full social run
